Политика Конфиденциальности (Privacy Policy)

Последнее обновление: 01 Марта 2026

1. Собираемые Данные

При использовании приложения Работа Тап AI могут собираться следующие персональные данные:

  • Вход и Регистрация: Имя, фамилия, номер телефона, адрес электронной почты, фото профиля.
  • Данные Профиля: (Соискатели) Образование, опыт работы, навыки. (Работодатели) Название компании, адрес, сектор.
  • Разрешения Устройства:
    • Местоположение (GPS): Для показа ближайших вакансий, только с вашего разрешения.
    • Камера / Галерея: Для фото профиля или логотипа компании, только с вашего разрешения.
  • Активность в Приложении: Просмотренные вакансии, заявки, история сообщений, избранные вакансии.
  • Автоматические Данные: IP-адрес, модель устройства, версия операционной системы.

2. Использование Данных

  • Выполнение функций приложения (отправка заявок, создание вакансий).
  • Создание прямой связи между работодателями и кандидатами.
  • Обеспечение безопасности и предотвращение мошенничества.
  • Улучшение пользовательского опыта.

3. Передача Данных

При подаче заявки открытые данные вашего профиля (имя, опыт, контакты) передаются соответствующему работодателю. Ваши персональные данные НЕ ПРОДАЮТСЯ сторонним рекламным компаниям.

4. Сторонние Сервисы

Приложение использует Google Firebase (Authentication, Firestore, Storage) для хранения данных. Ваши данные хранятся на серверах Firebase в зашифрованном виде.

5. Удаление Аккаунта (Data Deletion)

Чтобы удалить аккаунт:

  • Используйте кнопку Профиль → Удалить Аккаунт в приложении.
  • Или напишите на [email protected].

При удалении аккаунта все персональные данные немедленно (0 дней) полностью удаляются из нашей базы данных.
